# Phase 14 D2: the daemon runs MySQL, PostgreSQL and MongoDB

> Date: 2026-11-25 · Branch: `db-d2` · Plan and results: `docs/roadmap/phase-14.md`, "D1 results" and "D2 results" · Decision: D-061

## What shipped

- **`supervisor.rs`:**
  - New `Spec` fields:
    - `stop_timeout`: 10 s, or 60 s for a database;
    - `log`;
    - `ready_port` and `ready_file`: a server counts as running only once its port answers and its own socket exists.
  - `reconcile` and `restart` stop services outside the `slots` lock. Several stop in parallel.
  - The orphan check:
    - reads the pid file's first line;
    - compares `/proc/<pid>/exe` with the program on Linux;
    - sends SIGKILL after the stop timeout.
- **`releases.rs`:** `DB_MANIFEST_URL` (`DEVID_DB_MANIFEST_URL`), `fetch_db_manifest`, `db_artifact` (the platform entry's own version), `db_series`, `download_db`.
- **`db.rs`** (new):
  - `Engine`, its paths, `install` and `install_mongosh`;
  - `init`:
    - MySQL: `mysqld --initialize-insecure`;
    - PostgreSQL: `initdb -A trust`, plus Devid's `pg_hba.conf`;
    - MongoDB: an empty folder;
  - `spec`, with D1's settings;
  - `pick_port` and `check_socket`;
  - `Accounts` in `accounts.toml` (0600), and `password()` (24 letters and digits, from the system's random source);
  - `bootstrap`.
- **`config.rs`:** `[databases.<engine>]` with `series`, `port` and `enabled`.
- **`server.rs`:**
  - the requests `DbList`, `DbInstall`, `DbStart` and `DbStop`;
  - `status.databases`;
  - `services()` and `apply()` include the databases that are on;
  - `mail_taken` knows the databases' ports;
  - `find_updates` and `apply_updates` cover the database release (`Install::Db` and `Install::Mongosh`).
- **`crates/cli`:** `devid db list|install|start|stop`.
- **Tests:**
  - unit tests in `supervisor.rs`, `db.rs`, `releases.rs` and `config.rs`;
  - `crates/cli/tests/db.rs`;
  - `scripts/db-e2e.sh`, and the `db-e2e` job in `ci.yml` (Ubuntu and macOS).

## How `devid db start mysql` goes

1. **Install:** reads the series in use, else the engine's default (MySQL 8.4, PostgreSQL 18, MongoDB 8.0). If that series is not installed, Devid downloads it from `db-latest`, checks its sha256 and puts it in place. MongoDB brings mongosh along.
2. **Setup:** sets up the data folder once, outside the config lock.
3. **Port:** at the first start, takes the usual port or the next free one, skipping Devid's own ports, Mail's, the sites' and the other databases'. A saved port that another program holds is refused, with the program's name.
4. **Start:** saves `enabled = true`. `apply` adds the server's spec, and the supervisor starts it.
5. **Readiness:** waits up to 120 s for the server to count as running. If it does not, the error shows the end of the engine's log.
6. **Bootstrap:** runs once. MySQL gets the account `devid`. MongoDB gets the administrator `devid` and `root`. PostgreSQL needs nothing.

## Verification

- **Local:** on the M1, `cargo fmt`, `cargo clippy --all-targets -- -D warnings` and `cargo test` passed. `paths::tests::passwd_home_matches_home` fails under a fake HOME, as always, and passes with the real one. `crates/cli/tests/db.rs` takes about 4 s.
- **CI:** the new `db-e2e` job runs the real builds on Ubuntu and macOS.

## Gotchas

- **Test servers:** the fake servers in `crates/cli/tests/db.rs` listen through perl's IO::Socket::INET, which macOS and Ubuntu both ship. No test needed Python before.
- **MySQL's socket:** a long `DEVID_HOME` makes the path too long for MySQL, which D1 hit on the M1 with a long work folder. `scripts/db-e2e.sh` therefore uses a short folder under `/tmp`, and Devid says so instead of failing quietly.
- **`devid uninstall --purge`** still deletes `~/.devid/data`. D3 makes it keep the databases before any release.
