# Phase 6 E2: extension catalog in `devid-binaries`

> Date: 2026-11-04 · Repository: `devid-binaries` · PR: hadziqmtqn/devid-binaries#7 · Release: `2026.11.04-6`

## What shipped

- **Recipes:** `extensions/<name>.sh` for apcu 5.1.28, mongodb 2.5.5, ldap (from each PHP's php-src) and imagick 3.8.1. Each pins its source by SHA-256 and has a smoke test.
- **`scripts/build-ext.sh`:** runs in each PHP job after `build-php.sh`, against that job's build root. It writes `ext-<name>-<version>-php<minor>-darwin-x86_64.tar.gz` with `<name>.so`, `ext.json`, `LICENSES/` and `BUILDINFO`.
- **A build fails if** the shipped `.so`:
  - links a library outside `/usr/lib` and `/System`, or keeps an rpath;
  - has an undefined symbol that neither PHP nor a linked system library provides;
  - does not load in `php` and `php-fpm`, with and without Xdebug;
  - fails its smoke test.
- **imagick:**
  - builds ImageMagick 7.1.2-35 itself, with libxml2 for SVG and the gradient patch (ImageMagick/ImageMagick#9093, D-024); spc builds the format libraries;
  - ships `etc/policy.xml` and `etc/type.xml`;
  - its `ext.json` asks for `MAGICK_CONFIGURE_PATH=etc`.
- **`manifest.json`:**
  - gains `extensions.<php minor>.<name>` (version, type, file, `php_api`, license, source, env, and the archive's URL, SHA-256 and size);
  - `schema` stays 1, and Devid 0.2.3 reads the new manifest unchanged (`devid update --check`: "everything is up to date (release 2026.11.04-6)").
- **`release.yml`:** runs the catalog step, keys its cache on the recipes, allows 180 minutes, and has a `dry_run` input that builds and checks without publishing.
