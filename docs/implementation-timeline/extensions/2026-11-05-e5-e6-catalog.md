## Notes

- Every release rebuilds every extension, so `devid update` offers a "new build" of each installed one after a release. That is by design: an extension must match its PHP release and its OpenSSL.
- Reinstalling apcu through `devid update` also writes `apc.enable_cli=1` (v0.4.1).
