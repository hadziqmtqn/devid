# Phase 6 E4: catalog extensions in the TUI, several at once (v0.4.0)

> Date: 2026-11-05 · Branch: `feat/e4-tui-extensions` · Ships in v0.4.0 · Plan: [Phase 6, "E4 design"](../../roadmap/phase-6.md)

## What shipped

- **TUI:** the PHP menu has "Extensions…" (`e`); editing php.ini moved to `i`. The view lists:
  - the catalog for that version, each row with name, version, license and download size, or "installed <version>";
  - the Install button under a rule;
  - Xdebug/pcov and the bundled extensions.
- **TUI keys:**
  - `space` (or `enter` on a row) ticks extensions that are not installed, and `tab` jumps to the button;
  - `enter` on the button confirms, naming each extension in catalog order and the total download size;
  - `r` removes an installed one after its own confirmation;
  - `x`/`c` switch Xdebug/pcov;
  - after each action the view opens again with fresh data.
- **Progress:** the footer shows `⏳ installing 2/3 imagick… 52%`, then `checking …` and `restarting php-fpm …`, while the install runs in another thread.
- **Daemon:**
  - `PhpExtInstall { version, names }` installs each name with its own verification and preflight, and restarts php-fpm once;
  - the reply has one result per name, and a failure does not undo the others;
  - `PhpExtProgress` reports the running install. Downloads count for 0–90 % by bytes (the archive on disk against the manifest's size), and finished extensions and the restart share the last 10 %;
  - a second install is refused while one runs, and a drop guard clears the job whatever happens;
  - `PhpExtCatalog` now includes each archive's size.
- **CLI:** `devid php ext install <ver> <name>...`. It prints the same progress line when stdout is a terminal, then the summary and each failure's full message. The exit code is non-zero if any failed.

## Verification

- `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings` and `cargo test` pass.
- **Unit tests:**
  - `extensions_view_ticks_installs_and_removes`: ticking, installed rows, the empty-selection message, the confirmation in catalog order with size, going back, remove, Xdebug, esc;
  - `extensions_view_and_its_confirmation`: a render test;
  - `extension_progress_counts_bytes_then_steps`.
- **`tests/ext.rs`:** `install 8.5 imagick broken` installs imagick, reports broken with PHP's message, restarts php-fpm once, and exits non-zero.
- **Real release `2026.11.04-6` on the owner's Mac:** a separate daemon with its own home and ports.
  - `devid php ext install 8.4 apcu mongodb ldap imagick` in a pseudo-terminal printed `installing 1/4 apcu… 0%`, then mongodb 2–20 %, ldap 25 %, imagick 28 → 34 → 57 → 81 → 96 %, `checking 4/4 imagick… 96%`, `restarting php-fpm 8.4… 98%`, and `installed apcu 5.1.28, mongodb 2.5.5, ldap 8.4.27, imagick 3.8.1 · php-fpm 8.4 restarted`.
  - A second install during that run got "another extension install is running; wait for it to finish".

## Notes

- The interactive TUI itself was checked through its state and render tests, not driven by hand in a terminal.
