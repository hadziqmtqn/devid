# Phase 8 A5 part 2: app type, local port and commands in the TUI (v0.11.0)

> Date: 2026-11-08 · Branch: `feat/a5-tui`

## What shipped

- **Sites table:** a Type column, and a Serving column with the PHP version (or `proxy :<port>` / `static`), the local port (`busy` when another program holds it) and the number of running commands.
- **A site's menu:**
  - `y` App type… (follow detection, or one of the presets);
  - `m` Serve as…;
  - `p` Local port…;
  - `g` Commands… (start or stop one), `a` Start all, `s` Stop all, `x` Remove a command…;
  - `n` Add a command… (a suggestion, or a name and a command typed in).
- Every entry is a daemon request the CLI also sends (`app_set`, `app_reset`, `app_port`, `command_*`).
