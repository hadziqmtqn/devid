# Phase 8 A5 part 1: a site's detail view and running commands in the menu bar (v0.11.0)

> Date: 2026-11-08 · Branch: `feat/a5-app-ui`

## What shipped

- **Sites:** the type, local port and running commands on each row; the host opens the site's detail.
- **Site detail** (as in the approved Phase 8 prototype, without Share):
  - App: type, serving mode, PHP version, web root, single-page app, forward port.
  - Local port: on/off, the port, busy holder and "Check again".
  - Commands: Start all, Stop all, Add command, each command's state, Start/Stop, log, Restart and Remove.
- **Add a command:** name, command and the project's suggestions.
- **Menu bar:** the number of running commands next to the icon, Stop per command and "Stop all commands" (`status` adds `running_commands`).
- **Version:** 0.11.0.
