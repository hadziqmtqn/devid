# Phase 7 G5: one-line install with `--gui`, installed on the owner's Mac; Phase 7 done

> Date: 2026-11-06 · Repository: `devid` · Branch: `docs/g5-phase-7-done`

## What shipped

The details are in `docs/roadmap/phase-7.md`, "G5 as built".

- **One install command:** `curl -fsSL …/devid-latest/install.sh | sh -s -- --gui` installs the daemon, the CLI and Devid.app. Without `-s -- --gui`, no app. `install.sh` already passes its arguments to `devid setup`, so no code changed.
- **Where it is documented:**
  - the devid README (#53);
  - the `devid-binaries` README (hadziqmtqn/devid-binaries#10);
  - `release.yml`'s release notes;
  - the published notes of `devid-v0.7.0` and `devid-latest`, edited with `gh release edit`.
- **Release:** v0.7.0, from G4. G5 changed docs only.
- **Phase 7 is done:** PROJECT_CONTEXT, the docs index and the Phase 7 plan say so.

## Verification

## Follow-ups
