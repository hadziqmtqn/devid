# Dock and Cmd+Tab icon while the window is open; Remove site in the app

> Date: 2026-11-06 · Repository: `devid` · Branch: `feat/site-ignore` (with D-029, recorded in `daemon/2026-11-06-site-ignore.md`)

## What shipped

- **D-030:** while the window is open, the app is a regular macOS app, in the Dock and Cmd+Tab with Devid's icon. With no window it is menu-bar only, as before. `open_window` switches the activation policy. Closing the window restarts the app as icon-only (D-027), which takes it out again.
- **`crates/gui/icons/icon.icns`:** built with `iconutil` from ten PNGs, one per slot, drawn by `render.swift` from the logo canvas's "Ukuran ikon macOS" board:
  - 16 pt @1x without the prompt;
  - 16 pt @2x and 32 pt @1x with thicker strokes and no underscore;
  - 32 pt @2x and up the full icon.
  `tauri.conf.json` lists it before `icon.png`, so Tauri sets it as the app icon for an unbundled run. `Devid.app` (G4) carries it.
- **In the app:** "Remove site…", the Served / Removed filter, the full paths for `open` and friends, the folder-picker focus and the update hint for an older daemon. These are recorded in `daemon/2026-11-06-site-ignore.md`.
