# Phase 7 G2: the window's five pages, with every TUI action

> Date: 2026-11-05 · Repository: `devid` · Branch: `feat/g2-gui-pages`

## What shipped

- **`crates/gui/src/api.rs`:** the web view's API. The command table and the TUI-to-app mapping are in `docs/roadmap/phase-7.md`, "G2 as built".
  - **`daemon`:** one command sends any daemon request except `stop`. Installs are forced to download from the release.
  - **macOS actions:** `open`, `copy_url`, `server_config`, `choose_folder`, `doctor`, `devid_check` and `in_terminal`. Each checks its target against the daemon's data or a fixed list, so the page cannot open, read or run anything else.
  - **Capabilities:** `capabilities/main.json` allows these commands one by one, plus dragging the window.
- **`crates/gui/ui/`:** Sites, PHP (with the Extensions dialog), Web Server, Logs and Settings, ported from the prototype (D-026).
  - **Status card:** the sidebar card shows the status, with Restart, Stop all and Start all. While an action on running services runs (restart, stop and start, switching the web server), the card shows it.
  - **Other actions:** the clicked button shows the action, such as "Checking…" or "Installing…". Quick ones show only their toast. One action runs at a time, so other buttons are disabled meanwhile. The owner pointed out that a check for updates showed "Checking…" under nginx on the card.
  - **PHP pickers:** the site's PHP version and the default PHP use the prototype's select field. Its list is the same menu as the ⋯ menus, with a check on the current version. WKWebView draws a native `<select>` as a macOS pop-up button, which the prototype does not have; the owner asked for the prototype's look.
  - **Menus and confirmations:** the ⋯ menus use the keyboard (arrows, Escape). Confirmations follow D-026: a title, one sentence, Cancel and the action, red when it deletes something. Inside the Extensions dialog they sit inline.
  - **Extensions install:** it polls `php_ext_progress` every 200 ms for the CLI's progress line, then shows the CLI's summary.
  - **Logs:** the followed log is read every second from its last offset.
  - **Redraws:** a page redraws only when its data changes. The sidebar redraws only when its state changes, so polling does not reset the keyboard focus.
  - **DOM:** built with `h()`, which sets text only; the only markup is constant icon SVG.
- **Docs:** "G2 as built" in `phase-7.md`, PROJECT_CONTEXT, and the Cmd+Q check in the G1 record.
