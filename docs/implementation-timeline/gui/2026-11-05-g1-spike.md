# Phase 7 G1: Tauri spike, menu-bar icon and a read-only Sites window

> Date: 2026-11-05 · Repository: `devid` · Branch: `feat/g1-gui-spike`

## What shipped

- **`crates/gui`** (`devid-gui`): a Tauri 2.12.5 app, without default features (no asset compression, runtime ACL, X11 or D-Bus).
  - **Workspace:** it is a member but not a default member, so `cargo build` and `cargo test` of the daemon and CLI never compile Tauri.
  - **Menu-bar icon:** a template image (`icons/tray.png`), with Open Devid and Quit Devid. There is no Dock icon (`ActivationPolicy::Accessory`).
  - **Window:** created when opened and destroyed when closed.
    - It opens at 1080×680, shrunk to the primary screen's visible area, with a 760×520 minimum (D-026; one unit test).
    - The title bar is an overlay, so the sidebar runs under the traffic lights.
    - Opening from Finder or Spotlight again (macOS reopen) shows it.
  - **Restart on close:** when the last window closes, the app `exec`s itself with `--background`, so the window's leftover memory goes back to the system (D-027).
  - **Start options:** `--background` starts with the icon only, for launch at login (G3).
  - **Web view API:** two async Tauri commands, `status` and `sites`.
    - They are the only commands the app manifest defines (`build.rs`), and `capabilities/main.json` allows only them, plus dragging the window by its toolbar.
    - The CSP is `default-src 'self'`.
    - There is no plugin and no network port.
- **`crates/gui/ui/`:** the prototype's Sites page ported to plain HTML, CSS and JS (D-026).
  - **Content:** the sidebar with its sections (only Sites is active), the server status card, parked folders and the site list with Isolated and "PHP x not installed" tags.
  - **Theme:** light and dark follow the system.
  - **Rendering:** `<template>` and `textContent` only.
  - **Polling:** `status` every 2 s while the window is visible.
  - **Daemon down:** the app shows the daemon client's own error text.
- **`crates/gui/icons/render.swift`:** draws `icon.png` (logo C, 1024 px) and `tray.png` (the outline template, 40×44 px) from the logo's SVG geometry with CoreGraphics.
- **`crates/daemon/src/protocol.rs`:** `request()`, the socket client, moved here from the CLI, so the CLI, the TUI and the app share it.
- **CI:** a `gui` job (Ubuntu, `libwebkit2gtk-4.1-dev`) runs clippy and the tests for `-p devid-gui`.
- **Docs:**
  - **phase-7.md:** "G1 results".
  - **PROJECT_CONTEXT:** the numbers.
  - **DECISIONS.md:** D-027, accepted by the owner after trying the icon's restart.
