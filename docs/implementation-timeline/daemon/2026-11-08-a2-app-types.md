# Phase 8 A2: app types, detected and changeable, served as PHP, static or proxy (v0.8.0)

> Date: 2026-11-08 · Repository: `devid` · Branch: `feat/a2-app-types`

## What shipped

- **D-035, app types:** every site has a serving mode filled in by a detected preset, and the owner can change either.
  - **Presets:** Laravel, CodeIgniter 4/3, Symfony, WordPress, PHP, Next.js, Nuxt, Node.js, Vite, Static.
  - **Detection:** reads marker files only.
  - **Defaults:** a site that matches nothing is served as before.
- **Config:** `[apps.<site>]` holds only the overrides (`preset`, `mode`, `root`, `upstream`, `spa`, `pass_host`).
- **Daemon:**
  - `app_set` and `app_reset` requests. The `sites` reply carries the type, the mode, the upstream and the overrides.
  - php-fpm runs only for PHP-mode sites' versions (plus the default).
- **Web servers:** nginx, Caddy and Apache render the three modes.
  - **Proxy sites:**
    - forward to `localhost:<upstream>`, because Vite listens on `[::1]` only;
    - send `Host: localhost:<upstream>` and rewrite the site's own Origin (A1), with an opt-out (`pass_host`);
    - pass WebSockets and stream;
    - name the port when nothing answers.
  - **Static sites:** serve `about.html` at `/about`, and fall back to `index.html` for SPAs.
- **Apache fix:** hidden folders such as `/.git/config` were served on PHP and static sites. They are refused now, as on nginx and Caddy.
- **CLI:** `devid app show|set|reset [site]`, and a type column in `devid sites`.
- **Version:** 0.8.0.
