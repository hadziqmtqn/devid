# Phase 8 A4: user commands run by the daemon (v0.10.0)

> Date: 2026-11-08 · Repository: `devid` · Branch: `feat/a4-commands`

## What shipped

- **D-036, commands:** a site can have named commands (`[[apps.<site>.commands]]`), started and stopped one by one or all at once with `devid cmd`. The owner no longer needs a terminal for `npm run dev:pg:local` and `npm run dev:tauri`.
- **How a command runs:** `$SHELL -c '<run>'` in the site's folder, in its own session, with the login shell's environment, Devid's `php` and the folder's nvm Node first on `PATH`, and stdin `/dev/null`. Output goes straight to `~/.devid/log/app-<site>-<name>.log`.
- **Stop:** SIGINT to the whole group, then SIGTERM after 5 s and SIGKILL after 10 s, until nothing of it is left. A daemon stop stops every command; the next daemon stops what a crashed one left behind (pid file with the process start time).
- **States:** running, exited (code or signal) or stopped. Nothing restarts by itself.
- **Suggestions:** `dev*`, `start*` and `watch*` scripts from `package.json` with the lockfile's package manager, and Laravel's queue, schedule and Reverb workers.
- **`app reset`** keeps the local port and the commands; it resets the type only.
- **Version:** 0.10.0.
