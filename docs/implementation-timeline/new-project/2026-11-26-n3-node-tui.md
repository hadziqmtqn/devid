# Phase 15 N3: the Node.js templates and the TUI's wizard

> Date: 2026-11-26 · Branch: `phase15-n3` (on top of `phase15-n2`) · Plan and results: `docs/roadmap/phase-15.md`, "N3 results" · Decision: D-063

## What shipped

- **`newproject.rs`:**
  - **`NodeApp`:** the framework's npm package, preset, usual port and `dev` line, for nine templates.
  - **`node_satisfies`:** npm's `engines.node` ranges.
  - **`node_project`:** the check, the create tool with fixed options, and `npm install`. Express is written by Devid.
  - **`Runner::npm` and `Runner::npx`.**
  - **`templates_json`:** lists a missing Node.
- **`server.rs`:**
  - `free_dev_port`;
  - a Node.js site's preset, upstream and on-demand `dev`, set in the same `mutate` as its link and commands;
  - `--php` refused for Node.js templates;
  - `port` in the reply.
- **CLI:** `new_with_progress`, which the TUI shares; the dev port in the output; the Node.js templates in `--list`.
- **TUI:**
  - `NewView`, `NewField`, `Mode::NewProject`, `Mode::NewDone`, `Effect::NewProject`;
  - `n` on the Sites page;
  - `draw_new`, and the result popup.
  - The loop runs the job with its steps on the message line. A failure goes back to the wizard with the error.

## Checked

- `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, and `cargo test`.
  - `platform::macos::tests::an_open_connection_is_seen` failed once in the full run and passed three times alone. It checks TCP connections per process group and does not touch this change.
- Unit tests, `tests/new.rs` with a fake Node toolchain, and a draw test of the wizard.
- On the owner's M1, a second daemon made every Node.js template, and each opened through the proxy with its HMR socket upgraded. The TUI, driven in a pseudo-terminal, made a Laravel and a React project. See "N3 results".
