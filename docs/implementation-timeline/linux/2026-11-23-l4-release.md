# Phase 12 L4: install.sh, self-update and the Linux release build

> Date: 2026-11-23 · Branch: `linux-release` · Dry run: 45208363166

## What shipped

- **`release.yml`:** a `build-linux` job on Ubuntu 24.04, next to the Intel and Apple silicon builds.
  - It runs `cargo test --release`, then builds `--target x86_64-unknown-linux-musl --bin devid`.
  - It stops if the binary has a program interpreter or needs a shared library.
  - It runs `scripts/smoke.sh` with the real PHP and nginx, then `scripts/linux-e2e.sh` (setup, HTTPS, uninstall).
  - `publish` waits for it, lists `devid-linux-x86_64` in `checksums.txt`, and uploads it to `devid-v<version>` and `devid-latest`.
  - The release notes name the Linux build and what `devid setup` changes on each system.
- **`install.sh`:**
  - On Linux it downloads `devid-linux-x86_64`.
  - It maps `aarch64` to `arm64` and refuses Linux on arm64 for now.
  - It checks the SHA-256 with `sha256sum`, or `shasum` where that is missing (macOS).
- **Self-update:** it downloads `platform::DEVID_ASSET`, the binary for its own system (`devid-darwin-<arch>` or `devid-linux-<arch>`), instead of always the macOS one.
- **`smoke.sh`:** Apache's on-demand check runs only on macOS; on Linux, Caddy's still runs.
- **Tests:** the install.sh test runs on Linux too, and the self-update tests use the platform's asset name.
