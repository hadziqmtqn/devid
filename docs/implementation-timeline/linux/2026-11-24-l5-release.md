## Gotchas

- **Headless Brave and Firefox hung over SSH on this machine,** past every timeout, while headless Chrome works on CI runners. The browser checks ran on the desktop instead: `systemd-run --user brave-browser URL` opens a window there, since the user manager has the session's `WAYLAND_DISPLAY`, and the owner looked at it.
- **`pkill -f <pattern>` over SSH matches the remote shell's own command line,** since the pattern is in it, and kills the session. Write the pattern as `[x]yz`.
- **A host key warning on the first `ssh-copy-id`:** the router had given the VM an address that another device once had. Comparing the fingerprint on the VM with `ssh-keygen -lf` first, then `ssh-keygen -R`, kept it safe.
- **systemctl warned "unit file changed on disk"** on the first setup, which ran right after the machine's upgrade. Since #130 the root step reloads units before restarting anything.
