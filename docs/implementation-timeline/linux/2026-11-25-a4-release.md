## Gotchas

- **Plasma Login Manager replaces SDDM on CachyOS.** Its `wayland-session` script keeps SDDM's shell branches, so fish's `conf.d` reaches the desktop session.
  - To simulate a login, run the script with `env`: `sh wayland-session env`.
  - The script ends in an unquoted `exec $@`, so `sh -c '…'` gets split into words and prints nothing.
- **UFW on CachyOS** dropped SSH until the owner ran `sudo ufw allow ssh`. Devid itself needs no rule, since it listens on 127.0.0.1 only.
- **`. /etc/os-release` fails in fish,** because the file is shell syntax. The bug template now asks for `grep PRETTY_NAME /etc/os-release`.
- **Bridged Wi-Fi in Parallels** shows the old Mac's own MAC address for every VM in the ARP cache, so the VMs cannot be found by Parallels' MAC prefix.
- **`ananicy-cpp`** (CachyOS) core-dumps at every boot of this VM, reading Parallels' CPU list. It did so before Devid was installed too.
- **Disk:** the old MacBook Air had about 30 GB free. CachyOS used about 8 GB of its expanding 64 GiB disk (`df` inside the VM).
